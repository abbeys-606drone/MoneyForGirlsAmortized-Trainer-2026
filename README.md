## 🎮 About the Game

Money for Girls: Amortized is a horror-romance visual novel developed by Porpentine and released on August 24, 2026. It combines indie RPG and dating-sim elements with mystery, branching choices, fashion, stickers, and multiple endings.

---

## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Money for Girls: Amortized**. This trainer provides control over the game's core story-management systems, including money, mood, hygiene, outfits, stickers, and progression flags. It is designed to make route exploration, clue collection, and ending hunting more convenient without adding combat or changing the game's visual-novel structure.

**Target Audience:** Players who want to explore the branching mystery, relationships, outfits, stickers, optional scenes, and alternate endings with fewer resource restrictions. It is also useful for completionists and players replaying the story for missed routes.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

The game uses visual-novel navigation rather than free 3D movement. Select locations, activities, and available scenes from the story interface. Use the trainer's resource options to spend more time pursuing optional events without worrying about mood, hygiene, or money limits.

### Tools & Inventory

There is no traditional action-game inventory. Progress is represented through money, outfits, stickers, clues, photographs, route variables, and collected endings. Enable collection and progression options only when needed, then save after confirming that the relevant unlock has registered.

### World & Environment

Explore the locations of Sororal Quasisland through nonlinear story selections. Optional scenes, fashion choices, investigations, the Pink Market, and relationship events can appear according to time, resources, and previous decisions. Keep backups when testing different routes.

### Combat & Weapons

There is no conventional combat in the game. Conflicts are resolved through dialogue, investigation, resource management, relationship choices, and branching narrative consequences. Combat-related trainer options are therefore unnecessary.
